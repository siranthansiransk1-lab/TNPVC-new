## 4. Motion design system

Use GSAP as the primary animation engine if compatible with the existing stack. Do not install multiple overlapping animation libraries without a clear reason.

### Recommended techniques

1. **GSAP ScrollTrigger:** Trigger, scrub, and pin selected scenes. Pin only a few high-impact scenes; do not pin every section.
2. **Clip-path image reveal:** Reveal images through inset masks or a panel sliding away.
3. **Text line/word reveal:** Use a staggered upward reveal for selected headlines. Keep normal text readable and accessible. Use SplitText only if it is already available or its current license/setup is confirmed.
4. **Parallax:** Move separate foreground/background image layers by small distances to create subtle depth.
5. **Match cuts:** Transition from similar visual geometry between rooms, panels, materials, and finished interiors.
6. **SVG line draw:** Use for the dealer/partner network or visual connection between scenes, not as decoration throughout the entire page.
7. **Crossfades and restrained scale:** Use to connect leadership portraits and final scenes.
8. **Responsive motion:** Use desktop pinning only when it improves the story; use shorter reveal animations on tablets/mobile.

### Motion rules

- A single strong transition is better than five competing effects.
- Use smooth easing such as `power2.out`, `power3.out`, or `power2.inOut`; use `ease: "none"` for scroll-scrubbed transitions that must track scroll progress.
- Avoid large rotations, spring/bounce effects, overlong transitions, rapid flicker, and forced scroll-jacking.
- Do not animate layout-heavy properties continuously. Prefer `transform`, `opacity`, and carefully chosen `clip-path` transitions.
- Do not animate the pinned trigger element itself; animate elements inside it.
- Use `gsap.matchMedia()` for responsive and reduced-motion branches.
- Use `@gsap/react` and `useGSAP()` in React projects so animations and ScrollTriggers are cleaned up when the component unmounts.
- Do not assume a framework. Inspect the current project first and adapt the code to its actual React/Next/Vue/plain-JS setup.

## 5. Starter React + GSAP code pattern

**Use this only if the existing site is React.** Adapt class names, imports, TypeScript rules, styling system, routing, and component conventions to the actual repository. This is a starter pattern, not a replacement for reviewing the project.

If GSAP is not already installed and the project is React, install only what is needed:

```bash
npm install gsap @gsap/react
```

Example component pattern:

```tsx
import { useRef } from "react";
import gsap from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";
import { useGSAP } from "@gsap/react";

 gsap.registerPlugin(ScrollTrigger, useGSAP);

export function AboutMotion() {
  const rootRef = useRef<HTMLDivElement>(null);

  useGSAP(() => {
    const root = rootRef.current;
    if (!root) return;

    const media = gsap.matchMedia();

    // Full motion is enabled only when the visitor has not requested
    // reduced motion. Keep movement subtle and tied to the story.
    media.add("(prefers-reduced-motion: no-preference)", () => {
      const scenes = gsap.utils.toArray<HTMLElement>(".about-scene", root);

      scenes.forEach((scene) => {
        const revealItems = scene.querySelectorAll<HTMLElement>("[data-reveal]");
        const image = scene.querySelector<HTMLElement>("[data-image]");

        if (revealItems.length) {
          gsap.fromTo(
            revealItems,
            { y: 32, autoAlpha: 0 },
            {
              y: 0,
              autoAlpha: 1,
              duration: 0.85,
              stagger: 0.12,
              ease: "power3.out",
              scrollTrigger: {
                trigger: scene,
                start: "top 78%",
                toggleActions: "play none none reverse",
              },
            }
          );
        }

        if (image) {
          gsap.fromTo(
            image,
            {
              clipPath: "inset(10% 8% 10% 8% round 4px)",
              scale: 1.05,
            },
            {
              clipPath: "inset(0% 0% 0% 0% round 0px)",
              scale: 1,
              ease: "power2.out",
              scrollTrigger: {
                trigger: scene,
                start: "top 78%",
                end: "center 45%",
                scrub: 0.6,
              },
            }
          );
        }
      });
    });

    // Pin a single hero scene only on a wide screen and only when full motion
    // is allowed. Keep the rest of the page in normal document flow.
    media.add("(min-width: 1000px) and (prefers-reduced-motion: no-preference)", () => {
      const hero = root.querySelector<HTMLElement>("[data-about-hero]");
      const heroVisual = root.querySelector<HTMLElement>("[data-hero-visual]");
      const heroTitle = root.querySelector<HTMLElement>("[data-hero-title]");

      if (hero && heroVisual && heroTitle) {
        const timeline = gsap.timeline({
          scrollTrigger: {
            trigger: hero,
            start: "top top",
            end: "+=75%",
            pin: true,
            scrub: 0.7,
            anticipatePin: 1,
          },
        });

        timeline
          .to(heroVisual, { scale: 1.07, yPercent: -3, ease: "none" }, 0)
          .to(heroTitle, { yPercent: -14, autoAlpha: 0, ease: "none" }, 0.25);
      }
    });

    // Reduced-motion visitors should see every scene without being hidden
    // by animation setup or forced through pinned content.
    media.add("(prefers-reduced-motion: reduce)", () => {
      gsap.set(root.querySelectorAll("[data-reveal]"), { autoAlpha: 1, y: 0 });
      gsap.set(root.querySelectorAll("[data-image]"), {
        clearProps: "clipPath,transform",
      });
    });

    return () => media.revert();
  }, { scope: rootRef });

  return (
    <div ref={rootRef} className="tnpvc-about-motion">
      <section className="about-scene" data-about-hero>
        <div data-hero-visual data-image>
          {/* Use a real TN-PVC/project image or a properly licensed asset. */}
        </div>
        <p data-reveal>TN-PVC · ABOUT US</p>
        <h1 data-reveal data-hero-title>
          More Than Interiors. A Network That Builds.
        </h1>
      </section>

      <section className="about-scene">
        <div data-image>{/* Place the selected project/product image here. */}</div>
        <h2 data-reveal>From a single detail to a complete interior.</h2>
        <p data-reveal>
          Interior solutions shaped around spaces, products, and the people who bring them together.
        </p>
      </section>
    </div>
  );
}
```

### Code review requirements

- Check the installed GSAP and `@gsap/react` versions before using this example.
- Ensure every animation target exists and that a missing image does not break the page.
- Make sure the `media.revert()` cleanup is executed when the component unmounts.
- Avoid duplicate ScrollTriggers after route changes, React Strict Mode, or viewport resizing.
- Test for pinned-section jumps, horizontal overflow, broken anchor navigation, and mobile browser toolbar resizing.
- Do not put essential information exclusively inside animation callbacks or canvas/WebGL.
- If the current website is not React, do not introduce React solely for this page; use its existing framework.

## 8. Responsive, accessibility, and performance checklist

### Desktop

- Use one or two high-impact pinned scenes, not a pinned section for every block.
- Keep the user's navigation accessible and avoid trapping scroll.
- Use large editorial typography, image masks, cinematic pacing, and clean transitions.

### Mobile and tablet

- Do not force the desktop horizontal leadership sequence onto mobile.
- Replace pinned/horizontal sections with shorter vertical reveals where needed.
- Avoid overflow, tiny text, excessively tall scenes, and text over busy imagery.
- Test touch navigation and browser toolbar changes.

### Accessibility

- Honor `prefers-reduced-motion` and show content without requiring animation.
- Use semantic headings and alt text that describes meaningful images.
- Keep text contrast strong and buttons/links keyboard accessible.
- Do not autoplay audio. If video is used, provide a sensible poster/fallback and avoid sound by default.
- Avoid flashing, seizure-triggering effects, and motion that makes content difficult to read.

### Performance

- Use responsive image sizes and optimized WebP/AVIF where supported by the current pipeline.
- Use short, muted, compressed video clips only where they materially improve the story.
- Lazy-load below-the-fold imagery and avoid downloading all large video assets at page load.
- Avoid unnecessary WebGL/Three.js, multiple smooth-scroll libraries, and excessive particle systems.
- Reserve image dimensions to reduce layout shift.
- Test actual mobile performance, not just a desktop emulator.
